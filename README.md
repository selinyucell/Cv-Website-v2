# Cv Website v3 - Bootstrap

A personal portfolio website built for Selin Yücel, showcasing her skills, educational background, course experience, and contact information.

The project features a modern, responsive layout and is built using HTML, CSS, Bootstrap, and JavaScript.

## Demo

Open the `index.html` file in your browser to view the portfolio locally.

## Features

- Responsive and mobile-friendly design
- Fixed top navigation bar
- About section with personal information
- Skills section with progress bars
- Course cards showcasing technologies and programming languages
- Contact form section
- Modern and professional visual design

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Google Fonts
